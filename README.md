# 小白猫 × 何小狗

用 HTML 写的一个小站，送给何小狗。整站只有一个文件 `index.html`，双击就能打开，不需要联网、不需要安装任何东西。

## 地址

发布后（GitHub Pages）：

**https://chuyuxue.github.io/white-cat-letter/**

把这个链接存成手机桌面图标，点开就是全屏的样子（iOS：Safari 打开 → 分享 → 添加到主屏幕）。

## 里面有什么

- **🐾 爪印信箱** —— 每天打一次卡，选心情（累了 / 有点烦 / 想你了 / 还不错 / 超开心 / 就想看看你），小白猫回一句；还有摸摸头、抱一下。长按屏幕 0.65 秒有彩蛋，点右下角的小猫它会说话。
- **🐶 何小狗饲养手册** —— 喂食、遛弯、洗澡、犯错、想我、哄我、零食、睡觉，八个章节。连续打开 7 天会解锁「最终章」。
- **⏳ 未来时间胶囊** —— 七封信锁在里面，到日子才开（一周年、两周年、生日……）。

打卡记录、已读的信都保存在他自己的浏览器里（localStorage），换手机或清缓存会重新开始，这是正常现象。

## 想改内容，只改一个地方

打开 `index.html`，用搜索找到这一行注释：

```
✏️ 配置区：想改什么都在这里改
```

这行下面的所有内容就是全部文案，都是中文注释标好的：

| 想改什么 | 找哪个名字 |
| --- | --- |
| 六个心情的回应 | `MOODS` |
| 记完爪印后的菜单按钮 | `MENU_ITEMS` |
| 饲养手册的八个章节 | `MANUAL_SECTIONS` |
| 最终章 | `MANUAL_FINAL` |
| 时间胶囊里的信 | `CAPSULES` |
| 特殊日子（情人节、圣诞…） | `SPECIAL_DAYS` |
| 在一起的日子 | `TOGETHER_DATE` |
| 点小猫时它说的话 | `CAT_LINES` |

**别动** `下面是逻辑代码` 那一行以下的部分，那是功能代码。

### 改完记得改版本号

在配置区最上面：

```js
const PAGE_VERSION = "1.1.0";
```

每次改完内容，把最后一位加一（`1.1.0` → `1.1.1`）。页面左下角会显示这个版本号，他刷新后一看就知道有没有更新成功，也能排除「看到的是缓存的旧版」这种误会。

## 更新发布了怎么弄（每次 3 步）

1. 在电脑上改好 `index.html`（只改这一个文件）。
2. 打开 **GitHub Desktop** → 选这个仓库 → 左下角写一句话（比如「加了圣诞的话」）→ 点 **Commit to main** → 点 **Push origin**。
3. 等 1～2 分钟，让他刷新页面。如果还是旧的，让他下拉刷新一次，或者关掉页面重开。

> GitHub Pages 有大约 10 分钟的缓存，所以刚发布完可能还是旧版，等一下或者强制刷新就好。

## 第一次发布（只做一次）

1. 打开 **GitHub Desktop**，如果还没登录账号，先 Sign in（浏览器里点一下授权）。
2. 菜单 **File → Add local repository**，选择这个文件夹：
   `C:\Users\Lenovo\Desktop\white-cat-letter`
3. 右上角点 **Publish repository**：
   - Name 填 `white-cat-letter`
   - **如果想让对方点开链接就能看，把「Keep this code private」的勾去掉**（私有仓库免费版开不了 Pages）
   - 点 Publish
4. 浏览器打开仓库页面 → **Settings → Pages** → Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)` → Save。
5. 等 1 分钟，访问 `https://chuyuxue.github.io/white-cat-letter/`，能打开就成功了。

> ⚠️ 提醒：仓库公开后，**任何拿到这个网址的人都能看到里面的内容**（包括信里出现的名字）。网址本身不会主动被人找到，但本质上不是加密的。如果你介意，可以把仓库改成私有——代价是免费版用不了 Pages，对方就只能看你电脑上的文件或者你自己发给他，不能「点开链接直接看」。

## 屏幕适配说明

现在的布局不写死任何尺寸，手机、平板、电脑、横屏都能正常看。如果你以后要调，优先改 `:root` 里这几个变量，别去改具体元素：

| 变量 | 作用 |
| --- | --- |
| `--shell-w` | 中间内容列的最大宽度（宽屏时媒体查询会放大到 620 / 700px） |
| `--pad-x` | 左右留白 |
| `--tabs-h` | 顶部标签栏高度，**页面加载后由脚本实测覆盖**，不需要手改 |
| `--cat-scale` | 右下角小猫的缩放，屏幕矮的时候会自动变小 |

已经处理好的情况：

- 手机地址栏收起/展开（用 `100dvh`，不会被裁掉）
- 刘海屏 / 灵动岛 / 底部横条（`env(safe-area-inset-*)` 全方向都留了安全区）
- 窄屏标签折成两行（顶栏高度由脚本实测，下面内容不会被盖住）
- 横屏手机、浏览器窗口很扁（小猫缩小、隐藏次要文字）
- 很窄的手机（按钮改单列）
- iOS 横屏自动放大字号（已禁止）
- 系统的「减弱动态效果」（动画自动关闭）
- 有鼠标的电脑（补了悬停反馈）
